VYOMAA LABS

Real AI, built by a small team,
running off a phone.

Five AI projects, one shared on-device engine — no server farm, no funding round, just a phone that's part of the team. Vyomaa ("sky, boundless") is the idea: AI that does real work, quietly, close to the person using it.

CORE ENGINE

PocketMind

A small language model that runs fully on-device — on the same phone serving this page. No cloud call, no data leaving the device. Every project below is built on it, and it's the whole reason any of them are worth building: each problem already has a popular app online — this is the version that needs no internet and no server bill.

Matches YC Fall 2026's RFS "New Operating Systems for the Physical World" — software that does real work close to where it happens, instead of in a data center.

Four problems, one engine
MEDICINE

MedNotes

Turns a clinician's spoken case notes into structured, searchable records — on-device, so patient data never has to leave the room.

Closest to YC F26's RFS "AI for the Aging Population" — health monitoring and caregiving, the nearest fit this round since YC has no dedicated clinical-AI request.

FARMING

AgriLens

Point a phone camera at a crop, get an instant health read — built for fields with no signal and no patience for a 40MB app.

Matches YC F26's RFS "Data for the Real World," which names agriculture directly as one of the industries to digitize.

ECOSYSTEM

EcoTrace

Crowdsourced phone photos turned into a living map of local biodiversity and pollution, read and tagged automatically.

Same RFS, "Data for the Real World" — it calls out desertification and weather forecasting as the kind of real-world signal worth collecting.

EDUCATION

LearnLoop

A patient AI conversation partner for students to practice speaking and thinking out loud, in their own language, without judgment.

Matches YC F26's RFS "The Primer" — an adaptive AI tutor for reading, writing, and arithmetic at consumer scale.
